# AbridgeAI — Personal Learnings (git-excluded)

This folder is your **private interview-prep lab**. It exists only on this machine —
it is ignored via `.git/info/exclude` (local-only ignore, NOT `.gitignore`), so it
never appears on GitHub, and it never accidentally becomes a committed file.

## Contents
- `01-interview-questions.md` — 32 interviewer-style questions over 5 rounds, each with
  a strong-answer outline and a "how to recover if you blank" note.
- `02-mitigation-playbook.md` — universal recovery tactics + a patch plan for every
  weak spot found in the code.
- `03-github-worthiness-roadmap.md` — what to add/practice so this repo reads
  "hireable" by 2026 GitHub standards.

## How to use it
1. Answer `01` out loud, alone, 10 seconds per warm-up, 60–90s per deep question.
2. Any question you can't fully answer → write your own note under it, and do the
   corresponding drill in `02`.
3. Work through `03` one item per weekend — ship it to the repo, then re-answer the
   question it was meant to fix.

Pairs with the existing root `learnings.md` (build timeline + bug stories). This
folder drills you on that knowledge like an interviewer would.
